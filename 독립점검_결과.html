2. 우선 수정·보완할 점

F01 · 높음

AI 판단 품질을 정답지로 확인했다는 주장은 제공 설정과 맞지 않음

직접 확인: 설정 직접 열람. 채점 러너 tests/evals/와 정답·실행별 점수표는 ZIP에 없음. AI 판독·감독을 실행하거나 정확도를 재측정하지 않았다.

영향: 프롬프트 유지·형식 통과·절차 준수를 AI 판정 정확도 유지와 동일하게 말할 수 없다.

권고: 문구를 절차·형식 평가로 한정하고, 판독/감독의 독립 정답·채점 기준·모델/버전·반복 실행 결과·기준선 대비 점수와 허용 저하폭을 제공한다.

코드·파일 근거

reading-voc-comments/evals/evals.json:3 및 supervising-voc-disagreements/evals/evals.json:3은 정답/채점지가 없거나 비어 있으며 절차 준수만 검사한다고 명시한다. running-voc-engine의 작은 실행 시험도 66칸·산출물 생성 점검이지 정답 라벨 정확도 비교가 아니다.

F02 · 높음 · 재현

시각 정규화가 일반 업무 값의 차이까지 숨김

직접 확인: 합성 XLSX에서 같은 시각을 포함한 「규칙 A」를 「규칙 B」로 바꿔도 비교 결과 []였다. 합성 CSV에서 잰_날짜는 고정하고 다른 칸의 관측일만 바꿔도 []였다.

영향: “시각 값만 빼고 같은 행의 다른 값은 전부 본다”는 설명과 실제 동작이 다르다. 현재 실제 데이터에서 손실이 발생했다는 실측은 아니지만 검사기의 반례가 재현되었다.

권고: 파일·시트·열/키를 지정해 생성 시각 셀만 제한적으로 치환하고, XLSX 문자열 전체 대신 시각 부분만 바꾼다. 위 두 반례를 필수 음성 시험에 추가한다.

코드·파일 근거

대조장치/맞대기.py:79~87은 특정 CSV 행의 모든 시각 형태를 치환한다. 142~145는 첫 칸이 편향검사/잰_날짜인 XLSX 행에서 시각이 들어 있는 셀 전체를 <시각>으로 치환한다.

F03 · 높음

기본 실행은 brand_display 이외에도 의도된 의미 변경이 있음

직접 확인: 원본 ZIP의 build_master.py와 실제 배포 파일을 직접 대조했다. 전체 데이터로 변경된 행 수를 다시 측정하지는 못했다.

영향: ‘허용 차이는 brand_display 및 파생 칸뿐’이라는 총괄 결론은 기본 운영 경로까지 포괄하지 못한다. 옛 재현 스위치의 통과를 현재 기본 동작의 동등성으로 확대하면 안 된다.

권고: 옛 호환 모드와 개선 기본 모드를 구분하고, N/A·미분류·제외 사유·새 규칙 등 의도된 차이 목록과 각각의 범위·행 수·검증을 문서화한다.

코드·파일 근거

plugin/shared/tools/build_master.py:545~550 및 원본 스크립트의 독립 diff. 기본 경로는 N/A·미분류 행을 남기고, VOC_얼린기준_재현=1일 때만 옛 제외 동작을 재현한다. test_baseline.py:210은 이 변경을 별도로 검사한다. secondary_enums.json에도 video_transcript 제외 사유가 추가되어 있다.

F04 · 중간

2차 기준 생성에 후보의 수정 도구가 섞여 독립 기준의 범위가 제한됨

직접 확인: 코드와 설명에 교체 사실이 명시되어 있다. 특정 보정의 정당성 자체를 부정하는 결과는 아니다.

영향: 이 기준은 순수한 옛 배포 ZIP 실행 결과가 아니라 “옛 꾸러미 + 지정 패치 6개”의 결과다. 양쪽 공통 수정의 결함을 함께 통과시킬 수 있다.

권고: 패치를 파일별 diff·해시로 고정하고 기준 명칭/주장을 패치한 옛 도구 기준으로 좁힌다. 가능한 범위는 무패치 원본 실행과도 대조한다.

코드·파일 근거

직접 확인: 캐시값이 없는 =1+1 / =100+100 수식 차이와 셀 채움색 차이가 각각 []로 처리됨을 재현했다.

권고: 계약을 값 전용으로 명확히 하거나, 별도 수식/셀 유형/시트 표시 상태/스타일·너비/조건부서식 검사를 추가한다. “파일 전량”과 “속성 전량”을 구분한다.

코드·파일 근거

F06 · 중간 · 재현

잘못된 텍스트 인코딩이 같은 문자열로 뭉개져 통과 가능

직접 확인: 서로 다른 1바이트 파일 0xff와 0xfe를 a.txt로 비교했을 때 []였다.

영향: 읽기 실패를 같음으로 보지 않겠다는 의도와 달리, 디코딩 오류가 예외 없이 치환되어 비교된다.

권고: 엄격 디코딩으로 실패시키고 파일 경로·인코딩 오류를 보고한다. 정상 텍스트 여부를 먼저 검증한다.

직접 확인: atomic_id,wrong_column만 가진 합성 raw_voc.csv로 실제 실행하니 종료코드 0, 헤더만 있는 PL이슈.csv를 만들었다.
